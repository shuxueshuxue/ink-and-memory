# backend/script - Folder Contract

## Architecture Summary
Operational scripts for one-off or repeatable backend data maintenance tasks.
Scripts should reuse backend helper modules such as `database.py` where possible,
keep environment-specific values in CLI arguments or environment variables, and
avoid adding service runtime behavior.

## File Table

| File | Pos | Function |
|------|-----|----------|
| `import_diaries.py` | data-import utility | imports Markdown diary/note files into `user_sessions` with same-name folder date matching, `*-M-D.md` stem date matching, file-creation date matching, filename-first content, inferred labels, default OK mood, optional filename-date mode, title de-duplication, deterministic session IDs, and dry-run support |
