# backend/claude_agent — Folder Contract

## Architecture Summary
Claude Agent 应用层，迁移自 Pawkeyland `application/claude_agent/`。  
提供流式 AI 写作助手的业务逻辑（会话管理、上下文组装、SSE 事件），  
依赖 `backend/libs/claude_agent_kit/` 提供 SDK 封装和类型。  
与现有 PolyCLI agent 会话完全隔离。

## Migration Source
Pawkeyland `application/claude_agent/`（已移除 pet/persona/mem0/necklace 专属逻辑）。  
Kit 层（types/runner/workspace）已移至 `backend/libs/claude_agent_kit/`。

## Two-Layer Architecture
```
backend/libs/claude_agent_kit/   ← Kit 层：SDK 封装、类型、工作区
backend/claude_agent/            ← 应用层：业务逻辑、会话编排（本目录）
```

## Persistence Contract (aligned with better-chatbot)
**2026-06-09 P2 重构**：`_persist_turn` 拆分为三个独立方法：
- `_persist_user_message`：在 `execute_session` 调用 `runner.run_streaming()` **之前**立即写入用户消息（防止 thread 切换丢失）
- `_persist_assistant_turn`：turn 成功完成后写入 assistant 消息 + 更新 `claude_session_id`
- `_persist_partial_assistant`：SSE 流被取消/出错时 flush 已收集的部分 parts（metadata 标 `is_partial=true`）
- `_persist_turn`：保留为遗留别名，依次调用 `_persist_user_message` + `_persist_assistant_turn`

原有持久化字段不变：
- **user**：原始文本 + `parts_json`（含附件等 AI-SDK parts）
- **assistant**：`parts_json` 包含所有 `reasoning` + `tool-invocation` + `text` parts，`metadata` 含 usage/model/toolCount/is_partial

每次成功 turn 后，`_persist_assistant_turn` 还会将 `result.session_id` 和 `_AGENT_RUNTIME_CONTRACT_VERSION` 写回 `chat_thread`，下一轮 `assemble_context` 据此决定是否 resume。
