# backend/

## 架构概述
FastAPI + uvicorn Python 服务，端口 8765，提供 REST/SSE/WebSocket API，SQLite 持久化，可选 PolyCLI 编排。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| Dockerfile | 容器构建 | python:3.10-slim-bookworm，安装系统依赖、Node/Claude CLI、Claude sandbox runtime 与 Python 包，运行 uvicorn；包含 Docker/Linux Claude Code Bash sandbox 依赖 `bubblewrap` / `socat`，并确保标准 `sbin` 目录存在供 bubblewrap rootfs 挂载；Debian/PyPI/npm 源通过 build args 配置，默认使用国内镜像 |
| .dockerignore | 构建优化 | 排除 data/、__pycache__、.env、测试文件等 |
| docker-compose.yml | 单服务编排（旧） | 仅后端容器编排参考样例，已被根目录 docker-compose.yml 替代；保留 Claude Code bubblewrap Bash sandbox 所需 Docker runtime 权限 |
| API.md | api-doc | Backend API reference, including public SEO endpoints, authenticated Edit Session SSE events, Settings system-config fields, Google OAuth, OAuth Device Flow endpoints, and Claude Agent searchable thread history. |
| server.py | 后端入口 | FastAPI app、CORS 策略、SessionMiddleware、`/api/health`、公开 SEO 文件端点、路由挂载、DB 初始化、调度器启动 |
| config.py | 配置中心 | 从环境变量读取 LLM/API 配置 |
| seo_content.py | public-seo-content helper | Generate environment-driven `robots.txt`, `sitemap.xml`, and `llms.txt` content from `INK_PUBLIC_BASE_URL` and `INK_BACKEND_PUBLIC_BASE_URL` |
| database.py | 数据层 | SQLite 连接、模型定义、auth/OAuth/Device Flow 状态、voice 分区 Memory 配置持久化、Chat history search candidates |
| session_events.py | edit-session event bus | User-scoped Edit Session update/delete SSE fan-out for `/api/sessions/events` and Agent MCP write completion notifications |
| memory_workspace_defaults.py | procedural-memory-default-config node | 默认 procedural Memory prompt 配置，用于写入/回填 `voices.memory_workspace_config` |

| reflections_agent.py | reflections-agent runtime node | Reflections Agent 任务引擎、事件总线、持久化 Observer 与 UTC 时间戳生成，保持 Python 3.10 容器兼容 |
| notion/ | Notion resource connector backend | Notion connector auth/discovery/store/sync facade, SQLite persistence, canonical snapshot materialization, workspace attach helpers |
| auth.py | 认证 | 密码哈希、JWT access token、refresh token 生成/hash、HTTP Bearer token 验证 |
| routers/ | 路由模块 | 各业务领域的 FastAPI router |
| tools/ | Agent 工具 | MCP 工具实现 |
| claude_agent/ | Agent 运行时 | Claude agent 会话管理 |
