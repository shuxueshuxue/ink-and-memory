## 页面信息

### 1. 顶部导航

图片里最上方是轻量导航，不是重型侧边栏。

结构应为：

```txt
返回按钮 / 面包屑 / 当前连接器名称
```

用于告诉用户：
当前不是一个独立设置页，而是从“资源连接器”进入的某个连接器详情页。

---

### 2. 连接器头部区域

图片顶部中间有头像、标题、状态标签，右侧有两个操作按钮。

对应到你的业务：

```txt
连接器图标
连接器名称
连接器描述
连接状态
查看链接器设计稿
关闭连接
```

状态建议分成：

```txt
未认证
认证中
已连接
同步中
同步失败
已关闭
```

---

### 3. 主配置分区

图片中间最大的配置区域应转译为轻分区，而不是继续做成重卡片。页面只保留外层虚线纸边界，内部每一行用留白、轻列表背景和分隔线表达层级。

适合承载：

```txt
信息栏
资源选择
同步范围
权限范围
默认使用方式
```

不过你说“策略暂时不实现”，所以不要把策略做成完整表单。
否则页面会显得功能很多，但实际不可用。

---

### 4. 资源范围与已挂载来源

图片中部的资源区域应承载“选择可用资源”和“展示已挂载来源”两个明确任务。

资源范围标题使用：

```txt
资源范围
```

未认证时：

```txt
禁用状态
展示空态说明
提示先完成 Notion 认证
```

认证后：

```txt
展示统一资源列表
资源行用 Data source / Page 标签区分
People / Workspace user system data source 不展示
搜索框与「保存资源」同在操作行
默认每页 10 条
通过上一页 / 下一页翻页
点击资源行切换选中状态
点击保存资源后，已挂载来源立即显示所选资源
刷新页面后，已挂载来源从后端 persisted connector sources 恢复
```

交互草图：

```txt
资源范围 [搜索资源] [保存资源] [刷新同步]
  ├─ ☑ Data source · 产品资料库 · 18 pages
  ├─ ☐ Data source · 调研记录 · 12 pages
  ├─ ☐ Page · 品牌规范
  └─ [上一页] 第 1 / N 页 [下一页]

已挂载来源
  └─ 产品资料库 · Database · 已同步
```

---

### 5. 授权 / 同步解释位置

底部不再保留独立的“授权 / 同步状态”卡片，也不展示开关。

当前连接器为何受限，应统一由顶部信息栏解释：

```txt
授权状态：未认证 / 已认证 / 认证中 / 同步失败
挂载来源：当前已保存来源数量
最近同步：最近一次同步时间或未更新
```

## 关键交互规则

### 未认证状态

```txt
信息栏：可查看授权、同步、已链接资源数量和限制提示
资源选择：禁用
统一资源列表：不展示
已挂载来源：保留当前来源或显示空态
信息栏提示：完成 Notion 认证
```

### 已认证状态

```txt
信息栏：展示连接状态
资源范围：展示统一 data_source / page 列表
系统资源：不展示 People / Workspace user system data source
搜索资源：按标题 / 说明过滤
翻页：每页 10 条
保存资源：写入当前选择
已挂载来源：保存后立即展示所选资源和同步状态；刷新后从 connector sources 恢复
```

### 关闭连接

```txt
点击关闭连接
弹出二次确认
确认后：
  - 状态变为已关闭
  - 资源选择禁用
  - 已选资源保留但不可用
  - 对话页不再调用该 connector
```
