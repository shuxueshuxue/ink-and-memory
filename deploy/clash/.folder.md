# deploy/clash/

## 架构概述
本目录保存 Docker/Remote SSH Mihomo TUN 代理说明与非敏感配置片段；真实 `config.yaml` 来自用户本地 Clash profile，包含节点和订阅信息，必须保持 gitignored。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| README.md | Clash/TUN 使用说明 | 说明如何从本机 Clash profile 准备 `deploy/clash/config.yaml`，以及默认 Docker/Remote SSH Compose 如何通过 `tun-proxy` 路由后端出站 |
| config.tun-snippet.yaml | 非敏感 TUN 片段 | 提供需要合并进真实 Mihomo 配置的 `tun` / controller 配置示例 |
| .gitignore | 敏感配置保护 | 忽略真实 Clash/Mihomo 配置文件，只允许提交说明和非敏感片段 |
