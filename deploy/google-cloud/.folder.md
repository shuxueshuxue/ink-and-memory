# deploy/google-cloud/

## 架构概述
Google Cloud Run 发布脚本目录，作为云发布主入口；默认公开域名固定为 `ink-backend.suoxya.com` / `ink-frontend.suoxya.com`，旧 `deploy/*.sh` 路径仅保留兼容或被主入口编排。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| deploy.sh | Google Cloud 发布入口 | 检查云发布前置条件，编排存储初始化、环境变量初始化、镜像构建推送、Cloud Run 部署、后端 OAuth public URL、Secure cookie、CORS、`INK_PUBLIC_BASE_URL`/`INK_BACKEND_PUBLIC_BASE_URL` 回写、数据同步、云端 SQLite 本地备份、验证和回滚；部署摘要同时打印原始 Cloud Run 网关与固定公开根域名 |
| setup-storage.sh | Google Cloud 存储初始化 | 创建 GCS bucket、服务账号、IAM 授权并输出根目录 `.storage-env`；根路径 `deploy/setup-storage.sh` 仅做兼容委托 |
| sync-data.sh | Google Cloud 数据同步与备份 | 支持先下载云端 SQLite 到 `backend/data/bak_<date>/`；默认上传本地 SQLite 前先备份云端 DB，并用 `.cloud-env` 更新普通配置触发后端重启，同时过滤旧 public OAuth/CORS/cookie 配置后写回固定生产值；根路径 `deploy/sync-data.sh` 仅做兼容委托 |
