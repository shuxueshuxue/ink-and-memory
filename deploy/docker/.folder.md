# deploy/docker/

## 架构概述
Docker 发布脚本目录，复用根目录 `docker-compose.yml`、前后端 Dockerfile 和 nginx 模板。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| deploy.sh | Docker 发布入口 | 检查 Docker/Compose、本地配置和 `deploy/clash/config.yaml`，构建、启动、验证、停止和清理 Compose 服务；默认验证前端根路径 `/`；依赖根 Compose 让 backend 共享 Mihomo `tun-proxy` 网络命名空间，并为 backend 设置 Claude Code bubblewrap Bash sandbox 所需 runtime 权限 |

## Sync

- 2026-06-17: Root Compose backend requires `SYS_ADMIN` plus unconfined seccomp/AppArmor so Claude Code bubblewrap can create mount namespaces.
