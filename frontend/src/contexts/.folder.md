# frontend/src/contexts - Folder Contract

## Architecture Summary
React context providers for authenticated frontend state and workspace UI state.
Contexts should centralize shared app state that crosses view/component folders.

## File Table

| File | Pos | Function |
|---|---|---|
| `AuthContext.tsx` | auth-context provider node | Provide authentication state, token access, login/register/logout helpers, Google OAuth redirect, OAuth callback token consumption, and authenticated user metadata. |
| `WorkspaceContext.tsx` | workspace-context provider node | Provide active workspace session ID plus Settings-backed Workspace Mode enabled state for chat/file UI gating. |

## Sync

- 2026-06-22: Created folder contract; `WorkspaceContext.tsx` loads `system_config.workspace_enabled` and subscribes to same-tab Workspace Mode changes so chat/file sidebars close immediately when disabled.
- 2026-06-23: `AuthContext.tsx` consumes Google OAuth `access_token` URL fragments, exposes `loginWithGoogle()`, includes credentials on auth requests, and calls `/auth/logout`.
