# frontend/src/components - Folder Contract

## Architecture Summary
Top-level view components and shared UI widgets for the Ink & Memory frontend.
Each view corresponds to a navigation slot managed by `App.tsx`.
Sub-folders `chat/`, `dashboard/`, `Auth/`, and `Editor/` own focused feature areas.

## File Table

| File | Pos | Function |
|---|---|---|
| `AnalysisView.tsx` | `reflections-view node` | Reflections page — warm paper/vintage journal theme (Georgia, CSS design tokens). Dashboard view + PaperStack 3D stacked-paper report view + ReflectionBlogPage full-page blog view. Past Reflections cards open blog view; PaperStack retained for "View Reflections →" button. One-click 「Generate Reflections」 + per-section Analyze + ⚙ SectionConfigModal per section. DB-backed, rows grouped by day. Cards use unified `ReflectionResult[]`. |
