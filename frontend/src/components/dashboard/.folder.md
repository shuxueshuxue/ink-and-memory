# frontend/src/components/dashboard - Folder Contract

## Architecture Summary
Dashboard components for chat-adjacent navigation, file access, quick actions, model settings, and legacy sidebar surfaces.
These components should reuse existing chat icons, design tokens, and parent-owned callbacks instead of owning route state.
Vertical navigation currently exposes a theme-adaptive collapsible chat rail for files, chat history, and workspace controls; Settings is owned by top/mobile app navigation.
Resource connector surfaces live here as dashboard pages/panels and reuse the shared modal/icon/style primitives instead of introducing a separate route system.
The Settings resource-link gateway now lives here as `ConnectorSettingsSection`; `ConnectorNotionDetailPage` owns the single-account Notion detail shell and calls connector API helpers directly. `ResourceConnectorPage` remains legacy/compatibility workbench code and should not be embedded in the Settings Notion detail page.
Embedded connector mode keeps the visible workbench content as a created-connector view with normalized fallback data; the `添加源` action enters source management, which uses only the real selected connector context for empty/auth/resource-selection states.
