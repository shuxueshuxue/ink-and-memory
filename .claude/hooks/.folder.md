# Folder Plan: .claude/hooks

<!-- vibe-folder-map:start -->
## Architecture
- Scope: .claude/hooks
- Function: Hold project-scoped Claude Code hook commands. Hooks must be fail-soft unless they are explicitly guarding sensitive files.
- Sync: 2026-05-10 restored Mem0 context/stop hooks using origin/claude-runner's SessionStart/Stop lifecycle flow and AsyncMemoryClient search/add calls, with Volcengine `PAWKEYLAND_MEM0_API_HOST` config and the runner-injected `MEM0_USER_ID` memory index.

## Files
| File | Pos | Function |
|---|---|---|
| `protect-files.sh` | `guard` | PreToolUse hook that blocks direct Read/Edit/Write/View access to sensitive project files |
| `protect-files-bash.sh` | `guard` | PreToolUse Bash hook that blocks shell commands reading or writing sensitive project files |
| `mem0-context.sh` | `hook-shim` | SessionStart shell shim that runs `mem0_hooks.context_main()` |
| `mem0-stop.sh` | `hook-shim` | Stop shell shim that runs `mem0_hooks.stop_main()` |
| `mem0_hooks.py` | `hook-core` | Claude Code Mem0 hook core: searches current-turn shared memories with `PAWKEYLAND_AGENT_USER_MESSAGE` and writes Stop summaries under the claude-runner-style `MEM0_USER_ID`; `.env` loading is limited to Mem0 service config; diagnostics append-only to `$CLAUDE_PROJECT_DIR/logs/mem0_hooks.log` |
